# 任务 04: 测试、文档与运行说明

## 目标

让工具具备可维护性和可重复使用的运行说明，降低首次接入和后续排障成本。

## 实现要点

1. 补充 README 或等价说明，覆盖安装、凭据配置、状态文件说明、验证码识别依赖、`dry-run` 和正式执行方式。
2. 为时间过滤、状态记录、次数停止条件、验证码识别流程和配置模块补齐自动化测试。
3. 为登录/抓取/报名关键步骤输出结构化日志示例。
4. 记录当前已知站点行为、时间规则说明、验证码处理策略，以及执行阶段的人工验证步骤。

## 验证

1. 新用户仅依赖文档即可完成本地运行准备。
2. 自动化测试可以覆盖不依赖真实账号的核心逻辑。
3. 出现线上失败时，日志足以定位是登录、验证码识别、抓取、时间解析、次数判断、状态跳过还是报名阶段出错。
