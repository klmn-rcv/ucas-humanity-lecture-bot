# 任务 01: 项目骨架与配置

## 目标

建立一个可运行、可扩展的 Node.js 自动化项目，为后续浏览器自动化和业务逻辑提供基础设施。

## 实现要点

1. 初始化 `package.json`、TypeScript 配置、基础目录结构和脚本命令。
2. 引入 Playwright，并准备本地运行所需的浏览器依赖。
3. 建立配置加载模块，统一读取环境变量、运行参数、状态文件路径和验证码识别参数。
4. 设计讲座记录、时间过滤结果、终态记录、次数统计、验证码结果和运行结果等核心类型。
5. 提供 CLI 入口，支持 `dry-run`、状态文件路径、验证码开关和日志等级等参数。

## 验证

1. 项目依赖可安装，CLI 可启动。
2. 无凭据时能给出明确缺参错误。
3. 配置解析、状态文件路径解析和验证码参数解析逻辑有自动化测试覆盖。
