# 任务 1: 增加 8:00-18:00 每小时巡检与自动报名模式

## 要改什么

1. 在当前运行模型之上增加一个明确的“白天按小时巡检”模式。
2. 让程序支持从 8:00 到 18:00 每小时检查一次讲座信息。
3. 把巡检窗口改成数组时间段模型，允许同一天内配置多个不连续时间段。
4. 在该模式下，如果发现新的符合条件讲座，则自动报名，而不是只做一次性运行。
5. 该模式的参数优先从配置文件读取，而不是依赖长命令行参数。
6. 保持现有一次性 `dry-run` / 真实执行能力可用，不强制所有运行都进入调度模式。

## 依赖

1. 需要先明确新的配置文件结构。
2. 需要梳理当前 `pollIntervalMs`、`maxCycles` 与主工作流循环的现有语义。
3. 需要与筛选时间段的数组模型保持结构风格一致。

## 影响范围

1. `src/config.ts`
2. `src/types.ts`
3. `src/workflow.ts`
4. 可能涉及配置文件模板、CLI 与 README 中的运行命令表达
5. `src/schedule.ts`

## 如何验证

1. 调度配置能明确表达“8:00-18:00 每小时巡检”。
2. 可以表达同一天内多个不连续巡检时间段。
3. 不影响原有单次运行模式。
4. 相关测试能够覆盖默认模式和巡检模式。
