# 任务 2: 清理仓库结构并完善忽略规则

## 要改什么

1. 盘点当前仓库中不适合公开发布的文件与目录。
2. 删除不再需要保留的无关文件、一次性实验文件或纯本地调试残留。
3. 重写或补强 `.gitignore`，确保私人配置、本地缓存、日志、浏览器产物、虚拟环境和本地实验目录不会误入公开仓库。

## 依赖

1. 需要先确认当前仓库中哪些文件属于发布必需品，哪些只是开发期残留。

## 影响范围

1. 仓库根目录文件布局。
2. `.gitignore`
3. 可能涉及 `scripts/`、测试样本说明文件或其他辅助文件的保留策略。

## 如何验证

1. `git status --short` 中不再出现应被忽略的本地文件。
2. `.gitignore` 明确覆盖 `.env`、`.cache/`、日志、Playwright 产物、虚拟环境等目录。
3. 保留文件与 README 中描述的项目结构一致。
