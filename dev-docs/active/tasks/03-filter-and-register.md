# 任务 03: 过滤与报名执行

## 目标

根据固定时间规则筛选讲座，结合本地终态记录和次数停止条件，对命中且可报名的讲座执行实际报名操作。

## 实现要点

1. 实现固定时间规则判断：周一 17:00 及以后、周二 19:00 及以后、周三任意时间，其余时间全部跳过。
2. 读取本地状态文件，对“已预约”和“人数已满”的讲座直接跳过，避免重复访问和重复报名。
3. 在运行前和每次抓取后检查“已预约次数”与“次数要求”；一旦达到要求，立即停止新的报名动作。
4. 为每条讲座记录产出判定结果和原因，便于解释为什么命中、跳过或停止。
5. 在 `dry-run` 下只输出将要报名的目标，不执行点击或提交。
6. 在真实执行模式下触发报名，并校验页面提示、状态变更或结果弹窗。
7. 单次运行内对同一讲座去重，避免重复点击。
8. 报名成功、已预约或人数已满后，把对应讲座写入本地终态记录。

## 验证

1. 时间过滤逻辑和停止条件具备自动化测试。
2. `dry-run` 和真实执行模式行为明确区分。
3. 报名成功、已报名、人数已满、不可报名、提交失败等结果能被区分记录。
