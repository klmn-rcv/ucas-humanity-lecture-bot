# 任务 4: 将时间筛选条件改造成可配置模块

## 要改什么

1. 把当前写死在 `src/time-window.ts` 与 `src/filter.ts` 中的时间窗口规则抽离成可配置结构。
2. 把单个时间窗口结构升级成“按星期分组，每天可以有多个不连续时间段”的数组模型。
3. 让当前版本的筛选条件通过个人配置文件注入，而不是通过改源码或长命令行参数实现。
4. 保持当前版本只支持“按时间过滤”，不扩展成完整规则引擎。

## 依赖

1. 需要任务 3 提供新的配置文件入口。
2. 需要保留现有筛选行为作为默认兼容值或模板示例。
3. 需要与任务 1 的巡检时间段模型风格保持一致。

## 影响范围

1. `src/filter.ts`
2. `src/time-window.ts`
3. `src/config.ts`
4. `src/types.ts`
5. 配置文件模板
6. 相关测试文件
7. `README.md`

## 如何验证

1. 当前默认规则仍然能表达“周一 17:00 后、周二 19:00 后、周三全天”。
2. 可以表达“同一天多个不连续时间段”。
3. 不改源码也能通过配置调整时间规则。
4. `npm test` 中新增或更新相应测试，覆盖默认值与自定义值。
