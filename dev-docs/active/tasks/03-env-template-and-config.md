# 任务 3: 重建 `.env.example` 并引入配置文件入口

## 要改什么

1. 重新创建适合公开仓库发布的 `.env.example`。
2. 增加一个公开可复制的配置文件模板，用于承载巡检模式、筛选条件和非敏感运行参数。
3. 把当前运行所需的配置按职责拆分：敏感信息进 `.env`，非敏感行为配置进配置文件。
4. 减少对命令行参数的依赖，让命令行只保留少量调试或临时覆盖能力。

## 依赖

1. 需要先明确当前代码中的全部公开配置项。
2. 与任务 1 的巡检模式设计和任务 4 的筛选配置设计直接相关。

## 影响范围

1. `.env.example`
2. 配置文件模板
3. `src/config.ts`
4. `src/types.ts`

## 如何验证

1. `.env.example` 中不含真实账号、真实路径和个人偏好。
2. 配置文件模板中包含巡检与筛选所需的非敏感配置。
3. README 中提到的环境变量和配置文件字段都能在对应模板中找到。
4. `npm run typecheck` 和 `npm test` 通过。
