# 任务 02: 登录与讲座抓取

## 目标

自动完成 SEP 登录，进入人文讲座页，并把页面中的讲座列表、次数信息和报名状态提取成稳定的内部数据结构。

## 实现要点

1. 使用 Playwright 打开 SEP 登录页并填充用户名密码。
2. 检测页面是否出现验证码输入框和验证码图片；若出现，则截取验证码区域，做必要的图像预处理，并调用 OCR 识别文本后回填表单。
3. 依赖页面已有 JavaScript 完成 RSA 加密和表单提交，而不是手写登录请求。
4. 为验证码识别设计有限次重试与刷新验证码逻辑，连续失败时中止并输出明确错误。
5. 登录后访问人文讲座页，确认是否存在会话失效跳转，并在失效时给出明确错误。
6. 分析讲座列表 DOM，提取标题、开始时间、地点、报名状态、人数是否已满、操作按钮或讲座唯一标识。
7. 在页面中提取“已预约次数”和“次数要求”，并统一成内部计数字段。
8. 当页面结构不符合预期时，保留 HTML/截图/日志以便排障。

## 验证

1. 有效凭据下能进入受保护页面；如果出现验证码，验证码识别链路能够被触发并产生日志。
2. 能输出至少一组讲座记录对象，以及一份当前次数统计。
3. 登录失败、验证码识别失败或页面结构缺失时，错误信息可定位。
