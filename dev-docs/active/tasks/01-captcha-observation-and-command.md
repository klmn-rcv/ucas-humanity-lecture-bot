# 任务 1: 复核当前验证码实现与现场验证命令

## 目标

在不修改业务逻辑的前提下，确认当前验证码相关实现、推荐执行命令和关键日志点，为真实现场验证做好准备。

## 实施要点

1. 复核 `src/captcha.ts` 与 `src/login.ts` 中的验证码检测、OCR、刷新和重试逻辑。
2. 确认可用于现场观察的运行命令，优先使用 `--headful --dry-run --log-level debug`。
3. 明确现场需要重点观察的信号，例如验证码输入框是否出现、OCR 原始文本、回填值、登录页错误提示和刷新行为。

## 验证
