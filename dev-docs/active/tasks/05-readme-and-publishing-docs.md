# 任务 5: 完成 README 与公开发布说明

## 要改什么

1. 重写或大幅补强 README，使其适合首次接触项目的 GitHub 使用者。
2. 在 README 中说明安装方式、双层配置教程、运行命令、`dry-run` 与真实执行区别。
3. 明确写出校园网内外两种登录场景：
   - 校园网内通常不触发验证码时的推荐操作。
   - 校园网外可能触发图形验证码、后台调度需求和邮箱验证时的推荐操作。
4. 在 README 中加入后台运行方法，至少覆盖 macOS / Linux 与 Windows 的常见做法。
5. 在 README 中加入筛选条件配置教程，并明确当前仅支持时间过滤。

## 依赖

1. 依赖任务 1、任务 2、任务 3 和任务 4 完成最终的运行模式、项目结构与模板文件。

## 影响范围

1. `README.md`
2. 可能需要补充的测试样本说明或辅助文档。

## 如何验证

1. README 中的命令与 `package.json` 保持一致。
2. README 中的配置教程与 `.env.example`、配置文件模板保持一致。
3. 两种网络场景的说明都明确提到验证码、`--headful`、邮箱验证和后台运行方式。
