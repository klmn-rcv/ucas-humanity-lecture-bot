# 变更规格: UCAS 人文讲座自动报名

## 目标

构建一个可本地运行的自动化工具，能够登录中国科学院大学 SEP/选课系统，进入人文讲座列表页抓取讲座信息，按固定的时间筛选规则判断讲座是否符合要求，并在命中时自动发起报名。同时，工具需要跟踪已预约讲座、人数已满讲座，以及用户当前已预约次数和目标次数，在满足停止条件时自动结束运行。

## 范围

本次变更包含以下内容：

1. 提供一个命令行入口，用于执行一次“登录 -> 抓取讲座列表 -> 过滤 -> 报名”的完整流程。
2. 支持通过配置文件或环境变量注入账号、密码、轮询参数、本地状态存储位置，以及验证码识别所需参数。
3. 自动抓取讲座列表中的核心字段，至少覆盖标题、开始时间、地点、报名状态、人数上限状态，以及页面中可用于报名判断的标识信息。
4. 按以下固定时间规则筛选讲座开始时间：
   - 周一 17:00 及以后
   - 周二 19:00 及以后
   - 周三任意时间
   - 周四至周日全部排除
5. 读取页面中“已预约次数”和“次数要求”信息；当已预约次数达到或超过要求时，工具自动停止报名流程。
6. 对符合条件且当前可报名的讲座自动触发报名，并输出结构化日志。
7. 对“已预约”讲座和“人数已满”讲座做本地记录，在后续运行中避免重复访问详情或重复发起报名。
8. 如果登录页出现验证码，工具需要自动检测验证码区域，提取验证码图片并进行识别，再将识别结果填入登录表单。
9. 提供 `dry-run` 模式，只抓取和判定，不实际提交报名请求。

## 边界

本次变更不包含以下内容：

1. 不实现绕过短信验证、多因素认证或学校后续新增的高强度人机校验机制；当前仅覆盖图形验证码识别与填写。
2. 不承诺兼容所有未来页面改版；若页面结构变化，工具应报错并给出可定位信息，而不是静默失败。
3. 不实现云端托管、常驻服务或分布式调度，只提供适合本地定时运行的命令行工具。
4. 不保存明文密码到代码仓库；凭据只允许通过本地环境变量、`.env` 或运行时注入提供。
5. 不实现额外的通用规则编排系统；当前仅围绕已明确的时间筛选规则和停止条件实现业务逻辑。

## 验收标准

满足以下条件时，可认为本次变更完成：

1. 在提供有效账号密码的前提下，工具能够自动完成 SEP 门户登录，并拿到访问人文讲座列表页所需的已登录会话；如果登录页出现图形验证码，工具能够自动完成验证码识别与填写。
2. 工具能够读取人文讲座列表，并输出至少一份结构化的讲座记录集合，供时间过滤和报名逻辑使用。
3. 工具能够正确解析讲座开始时间，并仅保留以下时间窗口内的讲座：周一 17:00 及以后、周二 19:00 及以后、周三任意时间。
4. 工具能够识别并读取页面中的“已预约次数”和“次数要求”；当已预约次数达到要求时，不再执行新的报名动作，并明确输出停止原因。
5. 在非 `dry-run` 模式下，工具能够对命中且可报名的讲座执行报名动作，并记录成功、失败、已预约或人数已满结果。
6. 工具会把“已预约”与“人数已满”的讲座记录到本地状态中，使后续运行避免重复访问和重复报名。
7. 在 `dry-run` 模式下，工具不会执行真实报名提交，但会输出原本将要报名的目标讲座，以及会被跳过的终态讲座原因。
8. 如果验证码识别失败、验证码区域缺失或连续识别错误，工具会明确输出失败原因，而不是无限重试。
9. 工具对登录失效、页面结构缺失、报名按钮不可用、网络异常等常见失败场景有明确错误输出。
10. 至少为时间过滤逻辑、配置解析、终态记录、验证码识别流程和重复提交保护提供可自动化运行的验证。

4. 执行阶段仍需验证真实登录链路是否对自动化环境有限制，以及验证码图片是否适合本地 OCR 识别。
